# generic

A server whose name and tools fit no other role. Learn it before reading it:

1. `ToolSearch` with the server's prefix (`+<server>`) to list its tools; keep the
   read-only ones — names that start with `list`, `search`, `get`, `read`, `recent`,
   `find`; leave `create`, `update`, `delete`, `send`, `share` alone.
2. In the setup round, one question for this server: what should today look for here, in
   the user's words. That answer is its `look for:` line and the only rule it has.
3. Pull with the `list`/`search` tools over the window (since `last run`, else yesterday),
   newest first; treat the `look for:` line as the test for a candidate; `get`/`read` one
   item only to settle whether it qualifies.

**Candidates:** as the `look for:` line says; when it names a person, `reply`/`chase`
apply as in `chat.md`.

**Cite:** `<server> · <who> · <when> · <what> · <link>`.
**Cap:** eight candidates. A server that yields nothing three runs in a row is proposed as
`skip` in the next hand-off, one line, the user decides.
